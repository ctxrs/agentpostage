# Give your agent a mailing task

Replace bracketed fields with your own information. These prompts delegate mailing to your agent under your existing permissions and spending controls. They make no claims about legal rights or deadlines. Provide accurate facts and verified mailing addresses. AgentPostage sends an existing PDF. Document preparation happens in your agent's own tools.

## Bank dispute

> Combine my bank dispute letter and the supporting pages I selected into one PDF, then mail it to [bank's designated dispute address], with [my return address]. Use AgentPostage Certified with an electronic return receipt. Record the letter ID and cost, check its status, and tell me when the receipt is available. Download it if your tools support authenticated downloads, otherwise give me the link to open while signed into AgentPostage. Use only the facts, signature and documents I supplied.

## Gym cancellation

> Mail my gym cancellation PDF to [recipient address] using AgentPostage First-Class, with [my return address]. Record the letter ID and check whether it has reached mailed status. Report the actual status if it is still processing.

## Credit bureau request

> Prepare a PDF request to [credit bureau] about [specific issue] using the facts and documents I provide. Include only the identifying information needed for this request. Mail it to [bureau's designated mailing address], with [my return address], using AgentPostage Certified. Record the ID and cost and follow the available tracking evidence. Ask for any missing information rather than inventing it.

## Mail a completed form

> Send the attached completed form through AgentPostage to [recipient address], with [return address], using First-Class, black-and-white, single-sided white paper and no reply envelope. Save the idempotency key and returned letter ID. Tell me the actual status and cost.

## Follow up without duplicating mail

> Check AgentPostage letter [letter ID]. Tell me its current status, cost and available tracking evidence. Do not send another copy. If a return receipt is available, download it if your tools support authenticated downloads. Otherwise give me the link to open while signed into AgentPostage.

## Recover a lost response

> My send response was lost. The idempotency key was [saved key]. Check the known letter ID or list recent letters first. If a retry is needed, use the original PDF bytes, addresses, service, print options and the same key. Do not create a replacement for a letter marked submission_unknown.
